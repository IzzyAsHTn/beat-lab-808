Découpeur audio

Écoute un son, sélectionne le passage qui t’intéresse et exporte-le en WAV pour le glisser dans Logic Pro ou ton sampler.

Aucun fichier chargé—
Glisse sur la forme d’onde. Au clavier : flèches pour déplacer la fin, Majuscule + flèches pour déplacer le début, Alt + flèches pour un pas de 0,1 s ; Page précédente/suivante déplacent d’une seconde.
100%
00:00.000
Pour commencer : choisis un fichier, ajuste le début et la fin avec la forme d’onde ou les champs, puis écoute la sélection avant de l’exporter. Pour aller plus loin : isole une attaque de guitare ou une texture, puis importe le WAV dans Logic Pro pour le resampler, le renverser ou le traiter.

Décodage, écoute et export se font dans ton navigateur. Le fichier audio n’est pas téléversé vers GitHub.

Pour écouter : commence à volume modéré. Un casque est conseillé.
